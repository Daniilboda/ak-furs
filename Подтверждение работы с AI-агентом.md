Алгоритм простой: сначала строится словарь из справочника, потом каждая строка CRM ищет себя в этом словаре.

**1. Собрать словарь из листа «Менеджеры»**

Для каждой строки справочника:
- берётся каноническое имя, например `Ольга Ершова`;
- берётся список вариантов через `|`: `Ершова О. | Ольга | olga.e | О. Ершова`;
- в словарь кладутся и канон, и все варианты.

Ключ словаря — текст без пробелов по краям и в нижнем регистре (`casefold`). Значение — каноническое имя как в справочнике.

Получается примерно так:

| Ключ | Значение |
| --- | --- |
| `ольга ершова` | Ольга Ершова |
| `ершова о.` | Ольга Ершова |
| `ольга` | Ольга Ершова |
| `olga.e` | Ольга Ершова |

Если один и тот же вариант вдруг указывает на двух разных людей, загрузка справочника останавливается с ошибкой.

**2. Обработать строку заказа**

1. Взять поле «Менеджер», например ` olga.e `.
2. Убрать пробелы по краям → `olga.e`.
3. Привести к нижнему регистру → `olga.e`.

Вы это разруливаете так:
- одинаковое время + одинаковые поля → оставить одну (дубль);
