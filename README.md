# AK Furs — обработка выгрузок ателье

Скрипты сводят разрозненные выгрузки CRM, банка, прайса и переписок с клиентами в единые цифры и файлы для руководителя.

## Что делает

1. **Очистка CRM** — дубли строк, канонические номера заказов и клиентов, статусы, скидки, менеджеры, источники.
2. **Сверка с банком** — оплаты, привязанные к заказам; оплаченные заказы без поступления; неопознанные платежи.
3. **Ценовая политика** — строки, где цена после скидки ниже минимума на дату заказа (с учётом переименований артикулов).
4. **Переписки** — чаты, где менеджер пригласил на встречу или примерку раньше, чем назвал цену.
5. **Итог** — один файл `answers.json` и вспомогательные CSV/JSON.

Дополнительно: нормализация шапок чатов, черновик ответа клиенту, веб-UI для загрузки файлов и запуска расчёта.

## Входные данные

Папка `docs/` **не входит в репозиторий** (сырые выгрузки только локально). Создайте её у себя и положите файлы (имена можно менять — `solve.py` ищет CRM, выписку, каталог и zip чатов):

| Файл | Содержание |
| --- | --- |
| `01_crm_orders_export.csv` | заказы CRM |
| `02_bank_statement_rub.csv` | рублёвая выписка |
| `03_catalog_prices_reference.xlsx` | каталог, переименования, история цен, менеджеры |
| `04_client_chats.zip` | переписки `chats/Cxxxx.txt` |
| `answers_template.json` | шаблон полей итогового `answers.json` |

## Быстрый старт

```bash
# зависимости для тестов и Excel
python -m pip install pytest openpyxl flask

# полный пересчёт answers.json из docs/
python solve.py
```

Результат: `answers.json` в корне. Поле `notes` при пересчёте не затирается — сохраняется ваш текст из уже существующего файла.

Другая папка данных:

```bash
python solve.py путь/к/папке --out путь/к/answers.json
```

## Веб-интерфейс

```bash
python -m pip install -r UI/requirements.txt
python UI/app.py
```

Откройте http://127.0.0.1:5050 — загрузите четыре файла, нажмите запуск. На выходе: очищенный CRM, `answers.json`, сверка с банком и доп. JSON по чатам. Исходный `docs/` не меняется.

Мини-набор для проверки UI:

```bash
python UI/build_testdata.py
python UI/verify_testdata.py   # нужен запущенный UI/app.py
```

## Модули

| Папка | Назначение |
| --- | --- |
| `crm_cleanup/` | очистка CRM |
| `bank_reconcile/` | сверка с выпиской |
| `price_policy/` | нарушения минимальной цены |
| `client_chats/` | разбор переписок |
| `normilized_chats/` | нормализация шапок чатов |
| `proposed_reply/` | предполагаемый ответ клиенту |
| `reports/` | тексты для руководителя |
| `UI/` | загрузка файлов и запуск пайплайна |
| `tests/` | проверки `answers.json` и `solve.py` |

Каждый этап можно запускать отдельно (примеры команд — в `cursor_additional_files/commands.txt`).

## Тесты

```bash
python -m pytest crm_cleanup/tests bank_reconcile/tests price_policy/tests client_chats/tests tests -q
```

## Структура результата `answers.json`

- уникальные заказы и строки после очистки;
- номера оплаченных заказов без поступления в выписке;
- число и сумма неопознанных поступлений;
- число строк ниже минимальной цены и разбивка по менеджерам;
- ID чатов с приглашением раньше цены;
- `run_command` — команда полного пересчёта;
- `notes` — ваши пояснения к правилам (вручную).
