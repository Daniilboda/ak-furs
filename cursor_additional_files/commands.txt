========== crm_cleanup (этап 1) ==========

Универсальная команда:
python crm_cleanup/run_crm_cleanup.py --crm "docs/ИМЯ_выгрузки_crm.csv" --catalog "docs/ИМЯ_справочника.xlsx" --out-dir "crm_cleanup/normalized_crm" --only all

Параметры:
  --crm       сырая выгрузка CRM (обязательно)
  --catalog   справочник с листом «Менеджеры» (по умолчанию docs/03_catalog_prices_reference.xlsx)
  --out-dir   папка для результата (по умолчанию crm_cleanup/normalized_crm)
  --only      all | dedupe | normalize (по умолчанию all)

Результат: crm_cleanup/normalized_crm/<имя_исходного_файла>_cleaned.csv

Пример (текущие файлы):
python crm_cleanup/run_crm_cleanup.py --crm "docs/01_crm_orders_export.csv" --catalog "docs/03_catalog_prices_reference.xlsx" --out-dir "crm_cleanup/normalized_crm" --only all

Короткий вариант с дефолтами catalog/out-dir/only:
python crm_cleanup/run_crm_cleanup.py --crm "docs/01_crm_orders_export.csv"

Тесты этапа 1:
python -m pytest crm_cleanup/tests -q


========== bank_reconcile (этап 2) ==========

Универсальная команда:
python bank_reconcile/run_bank_reconcile.py --crm "crm_cleanup/normalized_crm/ИМЯ_cleaned.csv" --bank "docs/ИМЯ_выписки.csv" --out "bank_reconcile/results/q2_reconciliation.csv" --unidentified-out "bank_reconcile/results/unidentified_incoming.csv"

Параметры:
  --crm               уже очищенный CRM (*_cleaned.csv), имя файла может быть любым
  --bank              рублёвая выписка (имя файла может быть любым)
  --out               итоги Q2 (по умолчанию bank_reconcile/results/q2_reconciliation.csv)
  --unidentified-out  список неопознанных (по умолчанию bank_reconcile/results/unidentified_incoming.csv)

В консоль печатается JSON.
В --out пишется CSV: итоги Q2a/Q2b и ниже таблица неопознанных поступлений.
Отдельно обновляется unidentified_incoming.csv в results/.

Пример (текущие файлы):
python bank_reconcile/run_bank_reconcile.py --crm "crm_cleanup/normalized_crm/01_crm_orders_export_cleaned.csv" --bank "docs/02_bank_statement_rub.csv" --out "bank_reconcile/results/q2_reconciliation.csv"

Короткий вариант с дефолтными путями:
python bank_reconcile/run_bank_reconcile.py

Тесты этапа 2:
python -m pytest bank_reconcile/tests -q


========== price_policy (этап 3) ==========

Универсальная команда:
python price_policy/run_price_policy.py --crm "crm_cleanup/normalized_crm/ИМЯ_cleaned.csv" --catalog "docs/ИМЯ_справочника.xlsx" --out "price_policy/results/q3_price_violations.csv"

Параметры:
  --crm       очищенный CRM (*_cleaned.csv)
  --catalog   xlsx со скрытым «Прайс_история» и «Переименования»

Пример (текущие файлы):

Короткий вариант:
python price_policy/run_price_policy.py

Тесты этапа 3:

========== client_chats (этап 4) ==========

Разметка цен и приглашений (агент Cursor → JSON):

python client_chats/annotate_chats.py

========== solve.py (сдача, весь answers.json) ==========

Из корня проекта:

Или с папкой сырых файлов и явным выходом:
python solve.py data --out answers.json

В answers.json поле run_command = "python solve.py data"

Тесты сдачи:
python -m pytest tests -q

========== Порядок ==========

1) Сначала crm_cleanup → получается *_cleaned.csv
2) Потом bank_reconcile → читает этот cleaned и выписку
3) Потом price_policy → читает cleaned и каталог цен
4) Потом client_chats: annotate_chats → chat_annotations.json; из него — список Q4
5) Для сдачи: python solve.py data → answers.json из сырых data/
